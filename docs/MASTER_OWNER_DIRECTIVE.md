## 6. Immutable core, updates, disaster recovery

Signed verified atomic deployments, known-good rollback, protected boot artifacts, Secure Boot compatibility, integrity, least privilege, mandatory access controls, optional disk encryption, investigate TPM. Test invalid signatures, tampering, failed boot, power loss, disk full, interrupted download/upgrade and state migrations. Routine supported upstream security updates, emergency fixes and revocations do not require owner approval; never disable verification or bypass protected merges. Public LacOS releases still owner-gated; if our custom publication becomes necessary, establish an approved security-only servicing policy before release, not a delay on upstream patches. Preserve independent app/OS updates, Mint-inspired graphical management, recovery media and documented backup/restore for personal data and configuration. System rollback is not data backup. Test restore and recovery from actual failures. No security guarantees from immutability alone.
