# Synthetic backup/recovery evidence (P1 contract)

All bytes in this directory are generated by
`tools/lacos_backup_recovery/run_contract_checks.py` from fixed source
constants. No real guest, atomic deployment, mount, package database or live
owner-data path is read or written.

- `label`: `SYNTHETIC`
- real guest: `BLOCKED` / `NOT_RUN` (no Kinoite or Mint guest acceptance)
- `evidence_synthetic.json`: 22 bounded contract checks with per-artifact
  SHA-256 digests; regenerated deterministically on every run.
- `evidence_synthetic.json.sha256`: LF-only sidecar, verify with
  `sha256sum -c evidence_synthetic.json.sha256` from this directory.
- `fixture/source/**`: deterministic synthetic owner-data and versioned-state
  files. One file is temporarily tampered during verification, then restored
  to its exact original bytes.
- `fixture/state/**`, `fixture/planning_state/**`: synthetic durable checkpoint
  journals created inside this scratch tree only.
- `plan.json`, `manifest.json`: canonical projections used for digest evidence.

Regenerate (from the worktree root):

```
PYTHONPATH=<worktree-root> python -m tools.lacos_backup_recovery.run_contract_checks
```

Run the 13 host-local regression cases:

```
PYTHONPATH=<worktree-root> python -m unittest discover -s tools/lacos_backup_recovery -p 'test_*.py'
```
